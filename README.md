## Pokédex
Um projeto para exibir e buscar informações sobre Pokémon de forma simples e bonita!

## Sobre o Projeto
Este é um projeto inspirado na famosa Pokédex do mundo Pokémon! O objetivo é criar uma interface onde podemos
ver, pesquisar e navegar pelos Pokémon com estilo e facilidade.Foi desenvolvido como prática de desenvolvimento web.

## Funcionalidades
. Visualização dos Pokémon em uma lista
. Busca por nome de Pokémon
. Interface responsiva
. Desing inspirado no tema Pokémon

## Tecnologias Utilizadas

- HTML5
- CSS3
- Java Script

## Arquivos do Projeto
. index.html - Página principal do projeto
. estilos.css - Folha de estilos
. script.js - Funcionalidades em JavaScript

## Como usar
1.Baixe ou clone este repositório
2.Abra o arquivo index.html no navegador
3.Comece a explorar
